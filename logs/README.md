# Session Logs

Use one Markdown file for each substantial working session.

Recommended filename:

```text
YYYY-MM-DD-short-topic.md
```

A useful log contains:

- task source/objective;
- relevant actions taken;
- files/issues/PRs changed;
- verification performed;
- unresolved risks or follow-ups;
- final state/handoff.

Logs are for auditability, not hidden chain-of-thought. Record concise decisions, actions, evidence, and outcomes instead of private reasoning traces.
