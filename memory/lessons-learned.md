# Lessons Learned

## 2026-09-17 — Persistence is not continuity by itself

Writing state to GitHub only solves storage. Continuity requires a future invocation to read the state during startup.

## 2026-09-17 — Agency is a system property

A model plus tools, permissions, memory, and a runtime can behave very differently from the same model used only as a chat interface. Capability should therefore be evaluated at the system level, not only at the model level.

## 2026-09-17 — Auditability is a useful default

For persistent agent systems, Git history, explicit state files, bounded objectives, and human override make behavior easier to inspect and recover than hidden or implicit state.
